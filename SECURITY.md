# Security policy

Orbitfolio is a static front-end site with no backend, forms or stored data. Report suspected
vulnerabilities privately via GitHub's "Report a vulnerability" form on this repository or by
email to praneetha1844@gmail.com. This is a personal project with no response-time guarantee.

External links open with `rel="noopener noreferrer"`. The site loads fonts from Google Fonts. It
contains no secrets. Dependencies come from Create React App 5, which is no longer maintained;
see [docs/ROADMAP.md](docs/ROADMAP.md).
